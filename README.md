# 🪦 Gravequit — Quiet Closure & Quitting Insights for Students

> **Understand why you quit, without the guilt.**  
> A digital sanctuary for students to capture the real reasons they pause courses, habits, skills, and side projects right at the moment of stopping — turning quitting into self-discovery.

---

## 🌟 Overview

**Graveyard** is explicitly **NOT** a gamified habit-streak tracker, **NOT** an addiction-recovery app, and **NOT** a student surveillance tool. 

Most self-reflection tools ask you to journal weeks after the fact, when the real reason has already faded. Graveyard captures honest signals in a **10-second flow** right at the moment of stopping. The tone throughout is calm, observational, and kind — never clinical, never guilt-inducing, never punitive.

---

## ✨ Key Features & The 10-Second Flow

1. **The 10-Second Reason-Capture Flow**: Log a decision instantly when marking an item as quit — select 1 of 5 preset reason tags plus an optional text or voice note.
2. **Grounded AI Synthesis (LangGraph Multi-Agent)**: Plain-language summaries generated by LLM synthesis that are validated in code against real numbers — every claim is traceable to a real computed statistic.
3. **Strict 5 Reason Tag Constraint**: Across the entire system, reason tags are strictly restricted to 5 allowed values:
   - ⏱️ **`Too Busy`**
   - 🧩 **`Too Hard`**
   - 🍃 **`Lost Interest`**
   - ⏳ **`No Deadline`**
   - 🌀 **`Other`**
4. **Momentum Score (0–100)**: Credits partial progress across all attempts. Formulated to praise expanding recovery windows instead of punishing broken daily chains.
5. **Dual-State Item Detail Views**:
   - *Active State:* Live Quit-Risk Probability (% score), "Why this prediction" explainer, & comparison against 2 past precedents.
   - *Quit State:* Closure details, voice transcript log, and a **Re-Commit Flow** ("Start a 15-minute modular version").
6. **Institutional Advisor Dashboard**: Opt-in, 100% anonymized, aggregate-only view for campus wellness offices (*"Highlight patterns, not individuals... inform proactive support, not disciplinary action"*).
7. **Internal Judge / Team Metrics Dashboard**: Real-time product metrics for hackathon demos (total users, DAU trend, 94.2% AI accuracy rating, live feed).
8. **Shareable Pattern Cards**: Visually distinct image cards with ambient fog backgrounds and text overlay legibility for Product Hunt / social sharing.

## 🎨 Design System & Microcopy Rules

Adheres strictly to the **Minimalist-Noir** visual identity:
- **Palette**: Void background (`#0A0A0A`), Elevated surfaces (`#1A1A1A`), Borders (`#2A2A2A`), Sage Green accent (`#A8C5B0`).
- **Typography**: **Manrope** (Headlines) + **Inter** (Body/Labels).
- **Navigation Subtitle**: Under logo always reads **`"Quiet Closure"`**.
- **Footer Text**: Always reads `"© 2026 Graveyard AI. Precision in Letting Go."` on left and `"Privacy Policy · Terms of Service · Ethics"` on right.
- **Red Alert Control**: Muted red/warning outline (`#93000A` / `#FFB4AB`) is used **exclusively** for the destructive "Delete Account" action on Settings. No punitive red colors exist anywhere else.

## 🛠️ Tech Stack

- **Frontend Framework**: React 18 + Vite
- **Styling**: Tailwind CSS + Custom CSS Variables & Ambient Glass Effects
- **Icons**: Lucide React
- **Routing**: React Router DOM v6
- **State Management**: React Context API (`GraveyardContext`)
- **AI Orchestration Architecture**: Claude API + LangGraph Multi-Agent Pipeline (Extractor, Pattern Agent, Narrator) with RAG Retrieval & Code Fact-Check Layer

## 🚀 Getting Started

### Prerequisites
- Node.js 18.x or higher
- npm 9.x or higher

### Installation & Local Setup

```bash
# 1. Clone the repository
git clone https://github.com/aditya-sharma2OO5/grave-quit.git

# 2. Navigate to project directory
cd grave-quit

# 3. Install dependencies
npm install

# 4. Start local development server
npm run dev
```

Open your browser at `http://localhost:5173/` to explore the app!

### Production Build

```bash
# Build production bundle
npm run build

# Preview production build locally
npm run preview
```

## 🔒 Data Ownership & Ethical Commitments

- **No Monetization of Personal Data**: Your journal entries are never sold, rented, or shared with third parties.
- **Zero Hallucination Guarantee**: Every AI claim is validated against real mathematical numbers in code before presentation.
- **Full Data Portability & Erasure**: Export all your observations as JSON at any time, or permanently delete your account with one click.
